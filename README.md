# Shopify Stock & News Sentiment Analysis

This project combines time-series analysis and NLP to investigate the relationship between Shopify's stock performance and news sentiment over four years (2018–2022).

**Key components:**
- 📈 Historical stock data for Shopify (SHOP) retrieved via `yfinance`
- 📰 News headlines dataset from HuffPost (via Kaggle), filtered by date
- 🔍 Exploratory Data Analysis (EDA) of stock metrics and news category distribution
- 🧠 Machine Learning models including Random Forest, Logistic Regression, LSTM, and GRU
- 📊 Visualizations of price trends and standard deviations
- 🧪 Tools: Pandas, Seaborn, Scikit-learn, TensorFlow, NLTK

The project explores whether market trends correlate with news headlines, and tests predictive models for potential insights.
